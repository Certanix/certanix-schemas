schema.certanix.eu

This host is the published namespace referenced inside the signed bytes of Certanix evidence packs. Every pack names https://schema.certanix.eu/v1/evidence-context.jsonld in the bytes its signature covers, and the files listed below are what this namespace serves.

A dead link here never means a signature failed

Verification is offline and does not dereference this host. A verifier recomputes a pack's canonical bytes and checks the signature against a public key, with no network. If a file here cannot be fetched, a vocabulary could not be fetched. That is a different failure from a signature that does not verify, and only the second one is about trust.

Published paths are write-once

Once a schema is published at a path, the bytes at that path never change. A correction is a new path, such as a new pack version or a whole new /v2 prefix, with the old path left standing. The one exception is v1/evidence-context.jsonld, which is additive only: terms may be added, never removed and never redefined. Every digest is recorded at publication in CHANGELOG.md, the immutability ledger.
